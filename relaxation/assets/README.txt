Good sources: Freesound.org (search "rain window CC0"), Pixabay Audio.

Without this file the app generates a pink-noise fallback, which works but sounds synthetic.
Any stereo or mono MP3 at 44.1 kHz or 48 kHz works. The file is looped and mixed automatically.
